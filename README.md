## Sobre o projeto

Implementamos a **Opção 2** do enunciado da disciplina: um app de controle de acesso com três telas.

1. **Login**
2. **Listagem de usuários**
3. **Cadastro e atualização de usuário**

Os dados ficam no próprio aparelho, gravados com o [AsyncStorage](https://react-native-async-storage.github.io/async-storage/docs/usage).

## Tecnologias

- [Expo](https://docs.expo.dev/) (SDK 58) com React Native e TypeScript
- [React Navigation](https://reactnavigation.org/docs/getting-started/) (native-stack)
- [AsyncStorage](https://docs.expo.dev/versions/latest/sdk/async-storage/)
